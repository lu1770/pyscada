根據參考信息（台達 DTE 系列溫度控制器操作手冊），以下為整理後的通訊地址表。地址主要分為標準參數區（H10xx）、特殊功能參數區（H19xx/H48xx）以及可程式控制區（H20xx）。
### 1. 基本控制與監控參數 (H1000 - H10FF)
適用於通道 CH1 ~ CH8 (對應地址 H1000+通道偏移量)。
| 通訊地址 | 參數名稱 | 說明 / 數值範圍 | 備註 |
| :--- | :--- | :--- | :--- |
| **H1000** | PV 目前溫度值 | 0.1°C 單位 | CH1 (CH2=H1001 ... CH8=H1007) |
| **H1008** | SV 溫度設定值 | 0.1°C 單位 | CH1 (CH2=H1009 ... CH8=H100F) |
| **H1010** | 溫度偵測範圍最高值 | 超過預設值禁止 | CH1 (CH2=H1011 ... CH8=H1017) |
| **H1018** | 溫度偵測範圍最低值 | 低於預設值禁止 | CH1 (CH2=H1019 ... CH8=H101F) |
| **H1020** | 輸入補償值 | -999 ~ +999 | CH1 (CH2=H1021 ... CH8=H1027) |
| **H1028** | Pb 比例帶定值 | 0 ~ 9,999 | CH1 (CH2=H1029 ... CH8=H102F) |
| **H1030** | Ti 積分時間常數 | 0 ~ 9,999 秒 | CH1 (CH2=H1031 ... CH8=H1037) |
| **H1038** | Td 微分時間常數 | 0 ~ 9,999 秒 | CH1 (CH2=H1039 ... CH8=H103F) |
| **H1040** | 積分量預設值 | 0.0 ~ 100.0% | CH1 (CH2=H1041 ... CH8=H1047) |
| **H1070** | 讀寫第一組輸出量 | 0.0 ~ 100.0% | CH1 (CH2=H1071 ... CH8=H1077) |
| **H1078** | 讀寫第二組輸出量 | 0.0 ~ 100.0% | CH1 (CH2=H1079 ... CH8=H107F) |
| **H1080** | 警報一輸出上限值 | 溫度單位 0.1°C | CH1 (CH2=H1081 ... CH8=H1087) |
| **H1088** | 警報一輸出下限值 | 溫度單位 0.1°C | CH1 (CH2=H1089 ... CH8=H108F) |
| **H10A0** | 輸入感測器類型 | 0=K, 1=J... (詳見手冊P3) | CH1 (CH2=H10A1 ... CH8=H10A7) |

| **H10B0** | 輸出二控制選擇 | 0:加熱, 1:冷卻, 2:警報, 3:禁能 | CH1 (CH2=H10B1 ... CH8=H10B7) |
| **H10B8** | 控制方式 | 0:PID, 1:ON-OFF, 2:手動, 3:可程式 | CH1 (CH2=H10B9 ... CH8=H10BF) |
| **H10C0** | 警報一輸出模式 | 0:無警報 ~ 13:CT警報 | CH1 (CH2=H10C1 ... CH8=H10C7) |

| **H10D0** | 第二組輸出控制週期 | 0~99秒 (0為0.5秒) | CH1 (CH2=H10D1 ... CH8=H10D7) |
| **H10D8** | 控制執行/停止設定 | 0:停止, 1:執行, 2:結束, 3:暫停 | CH1 (CH2=H10D9 ... CH8=H10DF) |
| **H10E0** | PID自動調諧(AT)狀態 | 0:停止, 1:執行中 | CH1 (CH2=H10E1 ... CH8=H10E7) |
| **H10F6** | 通道禁能 | Bit0=CH1, Bit1=CH2... | 寫入數值控制 |
| **H10F7** | 濾波次數 | 0 ~ 50 (預設8) | |

### 2. 特殊功能參數 (H1900 / H4800 / H4700 區)
需先寫入 `H1234` 至 `H47F1` 開啟特殊功能設定權限，並透過 `H4824` 的位元啟用功能。
| 通訊地址 | 參數名稱 | 說明 / 操作方式 |
| :--- | :--- | :--- |
| **H47F1** | 特殊功能開啟 | 寫入 1234H |
| **H4821** | 輸出反向設定 | Bit0=CH1, Bit2=CH3... |
| **H4824** | 功能旗標控制 | Bit1:EVENT, Bit2:CT, Bit3:斷電儲存, Bit5:斜率, Bit6:熱流道 |
| **H482C** | CT 自動調整 | 寫入 1234H 啟動調整，讀取為 0000H 表示完成 |
| **H1960** | 熱流道界限溫度 | CH1 (CH2=H1961...), 單位 0.1°C |
| **H1968** | 熱流道固定輸出量 | CH1 (CH2=H1969...), 單位 0.1% |
| **H1970** | 斜率設定 | CH1 (CH2=H1971...), 單位 0.1°C/min |
| **H1978** | 可程式時間單位 | 0:分(預設), 1:秒 |
| **H1980** | 輸出最大值限制 | CH1 (CH2=H1981...), 單位 % |
| **H1988** | 輸出最小值限制 | CH1 (CH2=H1989...), 單位 % |
| **H1990** | 警報延遲時間 | CH1 (CH2=H1991...), 單位 秒 |
| **H1998** | EVENT 功能項目 | CH1 (0:無, 1:執行/停止...) |
| **H19A0** | CT 量測值(保持) | CH1 (CH2=H19A1...), 對應 CH1~CH4 |
| **H19A4** | CT 量測值(動態) | CH1 (CH2=H19A5...) |
| **H19B0** | 熱流道定時時間 | CH1 (CH2=H19B1...), 單位 分鐘 |
| **H19B8** | 輸入增益值 | CH1 (CH2=H19B9...) |

### 3. 可程式控制參數 (H2000 區)
用於設定 PID 程序控制的樣式與步驟。
| 通訊地址 | 參數名稱 | 說明 |
| :--- | :--- | :--- |
| **H2000** | 樣式0 目標溫度 | 樣式0包含步驟0~7，地址範圍 H2000~H2007 |
| **H2080** | 樣式0 執行時間 | 樣式0包含步驟0~7，地址範圍 H2080~H2087，單位：分 |
| **H2068** | 樣式0 最大步驟數 | 設定 0~7 表示執行至步驟 N |
| **H2070** | 樣式0 迴圈次數 | 0~199 代表執行 1~200 次 |
| **H2078** | 樣式0 連接樣式編號 | 設定下一個執行的樣式，8代表結束 |
*註：樣式1~7 的地址依此規則遞增。例如樣式1目標溫度起始地址為 H2008，執行時間起始地址為 H2088。*

### 4. 錯誤碼與狀態
*   **PV 讀取錯誤碼 (H1000~H1007)**：
    *   正常：讀出輸入值。
    *   **H8001**：EEPROM 無法寫入。
    *   **H8002**：輸入感測器未接。
    *   **H8003**：INB群組未接。
*   **LED 狀態 (H1124 等)**：
    *   Bit1: Alarm, Bit2: °C, Bit6: OUT1, Bit7: AT。
